# SmartServe Diner

SmartServe Diner is a smart canteen management system developed as an MCA major project. The application streamlines food ordering, menu management, and transaction handling through a digital platform.

## Features

- Digital Menu Management
- Online Food Ordering
- QR Code Based Access
- Transaction Management
- User-Friendly Interface
- Real-Time Order Tracking

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
